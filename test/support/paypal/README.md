# PayPal Disputes API validation snapshot

`disputes-v1-schema.json` is the unchanged version 1.12 API contract already
used by the dispute regression tests. It is stored here so a clean checkout
does not need private notes or a network download to run the tests.

API documentation: https://developer.paypal.com/docs/api/customer-disputes/v1/

Upstream specification repository:
https://github.com/paypal/paypal-rest-api-specifications

The API definition remains under its upstream Apache-2.0 license, included in
`LICENSE`. This snapshot is not asserted to be the latest upstream version.
No request expectations, measurement definitions, or schema rules were changed.
